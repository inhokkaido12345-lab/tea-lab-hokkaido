従業員向けヘルプ

従業員向け使い方ガイド

出勤・休憩・退勤、記録の確認、訂正申請、シフト、初回登録まで、このページで確認できます。

  • 出勤・休憩・退勤を打刻する
  • 自分の勤務記録を確認する
  • 打刻忘れ・間違いの修正を申請する
  • シフトを見る・希望休や変更を申請する
  • 初めて使う：ホーム画面へ追加する
  • 初めて使う：LINEでログイン・登録する
  • 困ったとき・管理者への連絡

初めて使う方は、先に本人のLINEで登録してください。登録済みの方は、以下の普段の操作から進めます。勤怠アプリを開く

1．出勤・休憩・退勤を打刻する

  1. 自分のLINEでログインしてアプリを開き、上部の会社・店舗名が自分の勤務先か確認します。
  2. 「打刻」タブを開き、勤務状態の読込みを待ちます。「未確認」のままなら「勤務状態を更新 ↻」を押します。
  3. 勤務を始めるときに「出勤する →」を押し、確認画面の内容が正しければOKを押します。
  4. 通信が終わるまで待ち、保存完了の案内・更新された勤務状態と「本日の予定と打刻」の時刻を確認します。

休憩・退勤も、それぞれのタイミングで下のボタンを押し、確認してから保存完了を待ちます。打刻する時刻はサーバーで記録します。画面の時計を書き換えたり、シフトを登録したりしても打刻時刻は変わりません。

いつ、どのボタンを押すか
タイミング押すボタン更新後の状態
勤務を始める出勤する →勤務中
休憩に入る休憩を開始する休憩中
休憩から戻る休憩を終了する勤務中
勤務を終える退勤する勤務外

通常は「出勤 → 休憩開始 → 休憩終了 → 退勤」の順です。休憩を取らなかった場合は「出勤 → 退勤」です。休憩を複数回取る日は、その都度開始・終了を押します。今の状態で使えるボタンだけが表示されます。シフトが未登録でも、本人の従業員登録と打刻受付が有効なら打刻できます。

中抜け・日またぎ・押し忘れのとき
  • いったん勤務を終えて中抜けする場合は「退勤する」。戻って勤務を再開するときは、勤務状態を確認してもう一度「出勤する →」。1日に複数の勤務を記録できます。
  • 日付をまたいで勤務が続く場合は、日付が変わっただけで出勤し直さず、実際に勤務を終えるときに退勤します。
  • 過去の押し忘れや誤打刻を、今の時刻の打刻を何度も押して埋め合わせないでください。下の訂正申請へ進みます。勤務途中で正しい操作が分からない場合は管理者へ相談してください。

ボタンを押しただけで完了とは限りません。通信中は連打せず、完了表示と記録を確認してください。保存結果が分からない場合は困ったときへ進みます。

2．自分の勤務記録を確認する

  1. 今日の分は「打刻」タブの「本日の予定と打刻」で確認します。表示が古い場合は「記録を更新」を押します。
  2. 「記録」タブを開くと、今日・今月の勤務を自動表示します。日ごとの詳細は月の記録の下の「日別の退勤記録を見る」へ進みます。
  3. 「表示する月」を選び、「日別記録を更新」で読み直します。日付ごとの出退勤・休憩・複数勤務を確認してください。

「勤務中」「未退勤」「未打刻」「予定なし」は、それぞれ意味が異なります。勤務が終わっていない日を0時間と解釈しないでください。実際と違う場合は訂正申請へ進みます。

シフトは予定、打刻は実際の記録です。新しいシフトは「シフト」タブで確認してください。日別記録に出る従来の予定比較や「予定超過」は、給与額や法定時間外の確定を意味しません。

3．打刻忘れ・間違いの修正を申請する

打刻を忘れた、時刻や休憩が間違っている場合に使います。従業員が申請し、管理者の承認後に記録へ反映されます。管理者本人の打刻も、本人用の同じ申請画面から申請します。

  1. 「打刻」タブの「自分の打刻を訂正申請」、または「記録」タブの「自分の打刻の訂正を申請する」を開きます。
  2. 必要なら自分のLINEでログインし、「自分の打刻の訂正申請」の画面を表示します。
  3. 「出勤日」を選び、正しい「出勤日時」「退勤日時」を日付と時刻まで入力します。すべて日本時間です。翌日に退勤した場合は退勤日時の日付も翌日にします。
  4. 休憩を取った場合は「休憩開始日時」「休憩終了日時」を両方入力します。休憩なしの場合は両方とも空欄にします。
  5. 中抜け後に再び勤務した日は「＋ 中抜け後の勤務を追加する」で、2回目以降の出勤・退勤・休憩も時刻順に入力します。
  6. 「訂正・申請の理由」に、何が違っていたかを入力します。例：「出勤ボタンを押し忘れたため」。500文字以内の1行で入力します。
  7. 「内容を確認する」を押し、表示された対象者・出勤日・すべての勤務区間・休憩・理由を読みます。この段階ではまだ申請されていません。
  8. 正しければ「確認した内容で実行する」を押し、確認画面でも内容を確かめてOKを押します。直したい場合は入力を修正し、もう一度「内容を確認する」から進めます。
  9. 「訂正申請を保存しました。管理者の承認待ちです。」と表示されたら申請完了です。表示された申請番号を控えます。「申請番号をコピー」も使えます。入力欄が空になるのは申請完了後の通常の動きです。

この申請は、その日を丸ごと訂正する内容です。間違った1か所だけではなく、変更しない正しい勤務も含め、その日の残したい勤務をすべて入力してください。元の打刻自体は残り、承認後の訂正履歴を追加する方式です。

承認待ちの間は、まだ勤務記録が変わらなくても異常ではありません。急ぐ場合は管理者へ申請した旨を連絡してください。承認後は「記録」→「日別の退勤記録を見る」で対象月を読み直し、正しい記録になったことを確認します。

実行ボタンが押せない・入力エラーになるとき
  • 「内容を確認する」を先に押して、確認内容を表示してください。入力を変えた後も確認し直します。
  • 出勤・退勤は時刻だけでなく日付も必要です。各勤務の出勤日は、上の「出勤日」と同じ日にします。退勤は出勤より後、未来の退勤日時は入力できません。
  • まだ勤務中で退勤時刻が決まっていない場合は、架空の退勤や予定時刻を入れず、管理者へ相談してください。
  • 休憩は開始・終了を両方入力するか、両方空欄にします。休憩の開始・終了は出勤と退勤の間で、開始より終了が後になるように入力します。
  • 中抜け後の出勤は前の退勤より後に入力します。最大10勤務、各勤務の休憩は1回またはなしです。複数回休憩など入力欄で表せない勤務は、勝手にまとめず管理者へ相談してください。
  • 画面のエラー文を確認し、指摘された欄を直してください。「日付・出退勤・休憩・理由を確認してください。」と表示された場合も、上記を見直します。
申請の結果が分からない・送信後に間違いに気付いたとき

「応答を確認できません」と出た場合は、画面を閉じず「内容を確認する」で同じ申請の結果を読み直してください。別の申請を作って送り直さず、解決しなければ管理者へ連絡します。

送信後の内容変更や取り下げは、対象日と申請番号を添えて管理者へ相談してください。この訂正申請画面には、本人が送信済み申請を取り消すボタンはありません。シフト希望の取消しとは別です。

自分の打刻の訂正申請を開く

4．シフトを見る・希望休や変更を申請する

  1. 「シフト」タブを開き、表示する月を選びます。翌年の月も選べます。カレンダー・申請一覧・共有出力は月全体です。表示は自動取得します。読み直すときは「シフトを更新」を押します。
  2. 「全員の確定シフト」で勤務予定・休暇・公開特記事項を確認します。更新されたかは最終更新日時で確認してください。空欄を休みと決めつけないでください。
  3. 希望休などは「自分の希望・変更申請」で日付・申請区分・予定や希望の種類を選び、必要な勤務区間・特記事項・理由を入力します。休みの希望は「公休・休みの希望」を選び、勤務区間を入れません。
  4. 「希望・申出を提出する」を押し、内容を確かめて確認します。締切未設定でも申請できます。翌年の希望も対象月・日付を選んで提出できます。締切が設定された後は、表示された締切前に提出してください。締切後で押せない場合は管理者へ相談します。
  5. 「自分の申請・本人同意の確認」で状況を確認します。未処理の自分の希望は、表示される「この申請を取り消す」で取消しできます。

確定後に変更したい場合も、月・日付を選んで変更理由を付けて申請できます。提出だけでは確定シフトは変わりません。管理者から変更案が届いた場合は、内容を読み「この変更案に同意する」か「同意しない」で回答します。同意後も管理者の最終承認を経て反映します。

「全員に公開する特記事項」は確定公開後に全員が見ます。個人的な事情は「非公開の特記事項」に記入してください。シフト希望の提出や確定は、実際の出勤・退勤の打刻とは別です。

確定シフトは「印刷・PDF保存」「PNG保存」「CSV保存」で出力できます。PNGは同じ確定シフト表の画像です。PDFは印刷画面で保存先を選びます。PNGを保存できない場合は、作成後の「画像を開く」から画像を長押しして保存します。LINE内で保存できない場合はChrome／Safariで開き、保存したファイルを自分で添付して共有します。

最初に：ChromeかSafariで開く

AndroidはChrome、iPhoneはSafariを開き、次のアドレスを入力してください。LINE内でこの説明を見ている場合も、ホーム画面への追加はChromeかSafariで行います。

https://tealabhokkaido.com/software/worktime/

旧URLからは新URLへ移動します。古いホーム画面アイコンでブラウザ枠や旧表示が残る場合は、新URLを開き、旧アイコンを削除して追加し直してください。アイコンを消してもサーバーの勤務記録は消えません。

「PWA」は、Webサイトをホーム画面からアプリのように開く仕組みです。App StoreやGoogle Playで探したり、ファイルをダウンロードしたりする必要はありません。追加せずブラウザから使うこともできます。

Android：Chromeから追加する

  1. Chromeで上記の勤怠アプリを開きます。
  2. 右上の「︙」メニューを開きます。
  3. 「ホーム画面に追加」または「インストールしてショートカットを作成」を選び、「インストール」「アプリをインストール」などの案内に進みます。端末・Chromeの版によって表示名が異なります。
  4. 表示された名前を確認して追加し、ホーム画面のTLHアイコンから開きます。

「ショートカットを作成」だけが表示される場合は、ブラウザで開く入口として追加できます。インストール表示がなくても、ブラウザ版は使えます。

iPhone：Safariから追加する

  1. Safariで上記の勤怠アプリを開きます。
  2. 共有ボタン（四角から上向きの矢印）を押します。Safariの配置によってはメニューボタンを開いてから「共有」を選びます。
  3. 共有メニューの「ホーム画面に追加」を選びます。見つからない場合はメニューを下へスクロールします。
  4. 「Webアプリとして開く」が表示される場合はオンにし、「追加」を押します。
  5. ホーム画面のTLHアイコンから開きます。

iOSの版によって配置や項目名が異なります。iPhoneの実機でのTLHログイン帰還は、まだ確認していません。うまく進まない場合は管理者へお知らせください。

初めて使う：本人のLINEで登録する

  1. 追加したアイコンから開き、「LINEログイン」が表示されたら押します。自分のLINEでログインして、元のアプリへ戻ります。
  2. 「その他」→「招待コードを受け取った方へ」を開きます。
  3. 管理者から個別に受け取ったコードを入力し、「このLINEで招待を受け取る」を押して内容を確認します。
  4. 登録後、「その他」のアカウント情報で氏名・社員番号を確認します。違っている場合は管理者へ連絡してください。

登録の案内が届いていない、または案内どおり進めても登録できない場合は、管理者へ連絡してください。氏名の手入力は不要です。必ず自分のLINEで登録してください。

すでに登録済みなら、ホーム画面へ追加したことを理由に登録し直す必要はありません。同じ本人のLINEでログインします。

困ったとき

ホーム画面に追加する項目がない
LINE内ではなく、AndroidはChrome、iPhoneはSafariで開いているか確認してください。追加できなくても上記URLから利用できます。
アイコンから開くとログインを求められる
本人の「LINEログイン」から進んでください。ブラウザでのログインがホーム画面版へ引き継がれない場合や、期限が切れる場合があります。
通信中のまま・保存できたか分からない
ネット接続が必要です。打刻の完了表示と記録を確認してください。結果不明なら新しい打刻を繰り返さず、画面の再確認・同じ打刻の再送案内に従い、解決しなければ管理者へ連絡してください。
打刻後に「同じ打刻を再送する」が出た
画面を閉じたり再読込みしたりせず、案内に従い同じ打刻の結果を確認します。保存済みの場合は追加されません。再送できない・整合性確認が必要と出た場合は操作を止め、管理者へ確認を依頼してください。
「有効な従業員登録がありません」「打刻受付は停止中です」と出る
招待受取りや利用設定を管理者に確認してもらってください。登録し直したり、別の人のLINEを使ったりして解決しようとしないでください。
打刻した時刻が違う・休憩を押し忘れた
打刻の訂正申請で、確認できた実際の勤務を申請します。
訂正申請したのに記録が変わらない
「管理者の承認待ち」ならまだ反映前です。申請番号と対象日を管理者へ伝えてください。承認後に日別記録を読み直します。
自分の氏名・社員番号などが違う
「その他」のアカウント情報を確認し、違っている項目を管理者へ個別に伝えてください。自分で登録し直す必要はありません。

管理者へは「対象の日付」「やろうとした操作」「表示された文言」を伝えてください。申請済みなら申請番号も添えます。必要なスクリーンショットは個別に共有し、招待コードや他人の情報をグループへ載せないでください。

ホーム画面への追加は、オフライン打刻やログイン不要になる機能ではありません。
