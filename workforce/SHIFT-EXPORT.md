# 確定シフトの表示・PDF・PNG・CSV

## 利用者の操作

従業員のシフトタブで公開済みの月を表示し「印刷・PDF保存」「PNG保存」「CSV保存」を選ぶ。PDFは印刷先の「PDFに保存」。背景が白くなる端末は「背景のグラフィック」をONにする。PNGが保存されなければ「画像を開く」から長押し保存。保存後、本人がLINEやメールに添付する。自動送信はしない。

## 表示の契約

社員を縦・日付を横にし、1〜15日/16〜月末の二表で表示。これは表示の分割で、公開は月全体、希望締切は任意範囲のまま。時刻は00分だけ短縮し、分・中抜け・翌日を残す。日数は各表の勤務予定日数、休は予定休憩で、実績や給与計算とは別。

公休は斜線、読み上げには公休文字を残す。休暇・未設定・未公開を公休へ変換しない。公開備考は本文だけで「共有事項：」は付けない。共有DTOの許可欄だけを出力し、希望理由/非公開備考/用事名・場所は含めない。本人限定欄は共有帳票へ混ぜない。CSVの詳細列/数式無害化と「公休」区分は保持。

## 配色・祝日・画像制限

日付/曜日 #E5EBE9、イベント #FFF7DF、公休 #EFF1EF、勤務 #FFFDFA、未設定/未公開・氏名/日数 #F3EFE7。土曜は青、日曜/公表済み祝日・振替休日は赤、祝日を優先。祝日表は2026/2027年が対象。追加年は内閣府の公表を確認してschedule-view.jsとGASのScheduleInputSheet.gsを同時確認する。自由入力イベントから祝日を推測しない。祝日色は法定休日/給与の判定ではない。

PDFはprint-color-adjust:exactを指定するが端末の印刷設定が優先する場合がある。PNGは標準Canvasで端末内生成し、新通信/外部サービスなし。幅2400px、高さ16000px/面積3200万画素の上限を超えたら縮小や行落ちでごまかさずPDFを案内する。連打中は無効、再読取/退場後の古い生成結果は保存しない。画像URLは再読取/退場で解放する。

## 魔改造MAPと検査

| 変更 | 編集元・連動先 |
|---|---|
| 純粋な社員×日付model・時刻・祝日 | schedule-view.js / schedule-matrix.test.mjs |
| 画面/PDF表・SVG斜線 | schedule-report.js のrenderMatrix / schedule.css |
| PNGの幅・折返し・Canvas・配色 | 同ファイルのdrawPng。配色変更はschedule.cssも同期 |
| 保存/印刷・無効化・画像解放 | 同ファイルinit / schedule-report.test.mjs |
| 詳細CSV | 同ファイルbuild/csv/headers。共有DTO許可欄だけを列挙 |

文字折返しの再利用はPNG1枚内だけ。削除すると計算回数が増えるが保存/認可は不変。PNG計算回数は `node scripts/measure-shift-png.mjs 12`、回帰は `node --test tests/*.mjs`。架空表示見本はprototypes/shift-matrix-preview.html、?print=1は印刷CSS相当の画面確認で、実PDF保存の代用ではない。
