## 月をまたぐ従業員メモ（2026-11-09）

入力ファイルの「従業員メモ」は全月共通の管理者用参考情報です。「継続メモ（管理者用）」列へ「火木不可」などを記入します。勤務の入力/取込みの禁止条件にはせず、月別の非公開備考や公開シフト/PDF/CSVへ自動転記しません。メモの編集はシートで行い、アプリは手編集しません。

内部employee_idで紐付け、社員番号変更時もメモを保持。新規月作成の明示操作では表を用意し、不足する社員行と社員番号/氏名の参照だけ更新します。既存メモ・過去社員の行は消しません。単なる読取り・取込みでは表を作成/更新しません。内部ID/ヘッダーを編集せず、メモ列だけを記入します。

# 正本シートの入力と取込み

管理者は「管理→シフトの管理→シフトの入力・取込み」で対象月を読み込み、「入力シートを開く」から編集します。接続先のURLは管理者確認済みの返信から表示し、公開ソースには実ファイルIDを置きません。従業員へシートを共有する必要はありません。

## 入力する場所

| 月別タブ | 記入するもの |
|---|---|
| YYYY-MM入力 | 1人3行：勤務・公開備考・非公開備考。日付/社員番号/行構造を維持 |
| YYYY-MM用事 | 会議・出張等の詳細と勤務算入 |
| YYYY-MM休暇詳細 | 月型欄だけでは表せない休暇の詳細 |
| YYYY-MM共有イベント | 営業上共有する祝日名・祭り・ライブ等 |

用事・休暇詳細等の具体的な列と選択値は各タブのヘッダー・使い方に従います。法令上の適否や勤務算入を不明のまま確定したものとして扱いません。土曜は青、日曜・収録済み祝日は赤です。祝日データの年次更新は必要です。

勤務例は `09:00-18:00/60`（予定休憩60分）。中抜けはセル内改行、日跨ぎは `22:00-翌06:00/60`。公休・有給等は対応する記号を入力します。社員番号を勝手に書き換えず、名簿変更は管理画面から行います。

**勤務・備考の空欄は、既存の内容を削除する指定です。** `【空にする】` は不要。月の行を削除したり、既存月を空のひな形で置き換えたりしないでください。公開備考は確定後に全員へ、非公開備考は本人・管理者だけに表示します。

## アプリへの反映

1. シートの編集を終えてから、同じ月の「入力シートから直接取り込む」を押します。CSVのダウンロードは不要です。
2. 勤務・備考・用事・休暇詳細・共有イベントの変更前後を確認します。空欄による削除も確認してください。
3. 「確認した正本シートを取り込む」で保存します。確定公開は半月管理画面で別に行います。
4. 確定済みの勤務変更は理由・本人同意・承認が必要です。申請承認の前には、正本を申請内容と一致させます。
5. 結果不明は同じ操作で再確認。確認後にシートが変わった場合は再読取します。

新しい月はアプリで月を選び「○年○月用の入力シートを作成」→確認して作成します。既にある月は保持します。勤務記入後に再作成・再移行を実行しないでください。

アプリの取込みは勤務原簿への直接セル書換えではありません。GASが認可・差分・版・保存後の読戻しを行います。バックエンドの原簿を直接編集しないでください。

旧CSV手順と空欄保持の説明は[過去の記録](history/20261109-SHEET-INPUT.md)です。正本モードでその手順を使いません。
