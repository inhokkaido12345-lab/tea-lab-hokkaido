# Account入口の文言整理（未公開候補）

対象はLINE認証、アカウント作成、利用開始コードの確認と、既存サービス管理への移動の区別。機能・認証・権限・保存契約を変更しない。

- 裸の/account/：共通アカウントと店舗アプリの利用手続き。
- ?service=inventory：店舗の在庫管理の利用手続き。このqueryは表示ヒントのみ、権限や入力コードのサービスを変更しない。
- ?purpose=personal&service=INVENTORY：個人利用、所属・コード不要の案内と既存の安全な戻り先を維持。
- LINE操作は「LINEでアカウントを確認」。未登録ならまずアカウント作成。
- コードの「次へ」は「コードの対象店舗・権限を確認」。ここでは確定しない。
- コードなしは既存サービス管理を開いて利用状況・申請先を見る。自動申請はしない。
- PREVIEW後だけ「確認した店舗・権限で参加する」、発行側は「確認した内容でコードを発行」。既存の確定条件と保存処理は変更しない。

単体50件成功。360/1280px×裸/在庫/personal×未登録/登録済みの実Chrome・架空署名応答による12ケースをqa/account-entry-wording-ci.mjsで検証する。外部HTTPを遮断し実LINE・実Account・実招待は使わない。CI画面と結果はaccount-entry-wording-synthetic artifact。

公開・権限追加・実アカウント操作なし。現行コードと同じ認証/保存/結果不明時のナビゲーションガードを維持する。
