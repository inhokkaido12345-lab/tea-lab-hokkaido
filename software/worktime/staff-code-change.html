社員番号の変更

既存の従業員を作り直さず、社員番号だけを変更します。内部の従業員ID、LINE連携、打刻・訂正・シフトの記録は保持します。

別の人が現在使用している番号へは変更できません。番号を移す場合は、先に現在の利用者の番号を変更します。番号変更だけではアカウントや権限は増えません。

LINEログインの確認・やり直し

同じ操作の結果が不明なときは、入力を変えず保存ボタンで同じ操作を確認します。ページを閉じた場合は、管理画面の最新名簿で新旧の番号を確認してください。Sheetの番号を直接書き換えないでください。
