# TLH Inventory

[在庫アプリ](https://tealabhokkaido.com/software/inventory/)。WorkTimeとは別のPWAです。

TLHアカウントでログインし、上部で店舗を選びます。「店舗を作成・招待コードで参加」から利用者が店舗を作成できます。作成者が管理者となり、7日間・1回限りの招待コードでメンバーを追加します。管理者は招待の取消・メンバー解除ができます。WorkTimeの雇用情報は変更しません。TLHアカウントの事前登録は必要です。

新店舗は空です。「仕入品情報」タブで品名・メーカー・複数の仕入先・商品コード・保管方法・規格資料を登録します。包装は「1ケース＝20袋、1袋＝20束、1束＝10g」のように登録し、自動換算します。例の数字を実商品に流用しないでください。現在はgを基準とする整数gの包装に対応し、Lをkgと見なす換算は行いません。価格・原価・POS連携は含みません。

仕入品情報の保存後に店舗別のGoogleスプレッドシートへ一覧を同期します。正本は検証付き原簿です。シートの直接編集はアプリへ反映されません。同期未確認の場合は「一覧シートへ再同期」を押します。在庫操作を重複登録する必要はありません。スプレッドシートの一般公開やGoogleメールアドレスへの自動共有はしません。

入荷は届いた時だけ在庫を増やします。消費計測は登録した1袋・1ケースの使用開始から使い切りまでです。毎回の計測は不要です。対象から順に使い、継ぎ足しや他包装との混用を避けてください。複数包装を同時使用すると店全体の消費速度を表しません。納期は発注〜受取完了で自動学習します。

店舗IDは権限ではありません。サーバーは毎要求でTLH本人確認を行い、最新の在庫サービス所属を検査します。他店舗の商品・履歴・仕入先は返しません。既存のThe TEA店舗だけは従来の固定Coreで認可された従業員向けの互換入口を残します。

PWAのid・scopeは/software/inventory/。認証窓口は既存の/workforce/inventory/auth/を使います。LIFF往復後も同一originのnonce固有BroadcastChannelで結果を受け取ります。token・鍵・結果のブラウザー保存やオフライン送信はありません。

再構築の正本は非公開tlh-inventoryのweb、src、gas、scriptsです。新しいバックエンドAPIを先に配備し、公開healthと匿名拒否を確認してからPWAを更新します。GAS原簿は最大10000操作で停止するため、大規模運用前には保存先の分割・DB移行が必要です。
